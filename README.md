# Living World

**Living World** — мод для **Minecraft 1.12.2**, добавляющий A-Life-симуляцию: животные и жители получают собственные потребности, поведение и распорядок. Мир продолжает жить, даже когда игрок находится далеко от конкретного места.

Мод не добавляет новые измерения, биомы или атмосферные эффекты. Его основная задача — сделать поведение уже существующих существ более самостоятельным и разнообразным.

## Совместимость

- **Minecraft:** 1.12.2
- **Minecraft Forge:** 14.23.5.2859
- **Java:** 8
- **Версия мода:** 1.0.0

## Возможности версии 1.0.0

### Животные и потребности

- У животных есть показатель сытости, который постепенно уменьшается.
- При низком запасе сытости животные ищут доступную пищу.
- Травоядные могут поедать траву; для подходящих видов реализовано естественное кормовое поведение.
- Куры и свиньи могут искать подходящую пищу на земле, включая выпавшие предметы и некоторые природные блоки.
- Животные разделены на группы по типу питания: травоядные, всеядные и хищники.
- При длительном голодании животные теряют здоровье. Это правило учитывается и в симуляции существ вне загруженных чанков.

### Охота и взаимодействие

- Волки охотятся на овец и кроликов.
- Оцелоты охотятся на куриц и кроликов.
- Хищники ищут добычу поблизости и преследуют её.
- Животные могут объединяться в небольшие стада.
- Участники стада способны реагировать на находящихся рядом враждебных существ и подавать сигнал тревоги.
- Стада формируются с учётом вида животных и расстояния между ними.

### Размножение и взросление

- Взрослые животные могут самостоятельно находить партнёра.
- Для размножения учитываются сытость, возраст, здоровье и время восстановления после предыдущего размножения.
- Размножение не происходит непрерывно: между попытками и новыми циклами предусмотрены задержки.
- После появления потомства животное проходит период взросления.
- Мулы исключены из размножения.
- Для поддерживаемых зарегистрированных типов животных предусмотрена обработка размножения в офлайн-симуляции.

### Распорядок дня

- Травоядные и всеядные животные получают простой режим отдыха в ночное время.
- Поведение распределяется по времени и индивидуальным смещениям, чтобы существа не выполняли все проверки одновременно.

### Жители

- Жители могут учитывать расположенные поблизости дома и рабочие места, соответствующие их профессии.
- Для жителей реализовано базовое поведение, связанное с перемещением к дому и рабочей станции.
- При обнаружении поблизости враждебных существ жители могут пытаться убежать.
- Поиск рабочих мест учитывает только загруженные области мира.

### Симуляция мира вне загруженных чанков

- Данные отслеживаемых существ сохраняются отдельно для каждого измерения.
- Для существ в незагруженных областях продолжается облегчённая симуляция выбранных параметров: возраста, сытости, голодания и размножения.
- Потомство, появившееся в офлайн-симуляции, сначала хранится как виртуальная запись, а не как настоящая сущность Minecraft.
- Когда соответствующий чанк естественным образом загружается, мод пытается создать настоящую сущность из виртуальной записи.
- Перед материализацией проверяется UUID, чтобы не создавать дубликаты.
- Мод не загружает чанки принудительно ради симуляции.

## Оптимизация и производительность

В версии 1.0.0 проведена отдельная работа над снижением лишней нагрузки на процессор, память и обработку сущностей.

- **Периодическое обновление:** основные данные отслеживаемых сущностей обновляются с интервалом, а не пересчитываются каждый игровой тик.
- **Пространственные индексы:** поиск подходящих партнёров для офлайн-размножения, кандидатов для стад и ближайших угроз ограничен соседними ячейками пространства вместо полного перебора всех записей или сущностей.
- **Общий индекс угроз:** поиск враждебных существ для животных и жителей использует общий индекс, подготовленный на один цикл обновления.
- **Повторное использование коллекций:** временные списки, множества и карты в трекере переиспользуются между обновлениями, чтобы уменьшить создание краткоживущих объектов.
- **Меньше временных BlockPos:** при поиске травы, природной пищи и рабочих мест используются изменяемые координаты; неизменяемая позиция создаётся только для найденной цели.
- **Разнесённые проверки:** некоторые поисковые действия животных и проверки угроз распределены по времени, чтобы не создавать одновременные всплески нагрузки.
- **Без принудительной загрузки чанков:** офлайн-симуляция работает с сохранёнными данными, а поиск целей и перемещение ограничены загруженными областями.
- **Безопасная обработка списка сущностей:** обновление поведения использует снимок списка загруженных сущностей, чтобы их появление или удаление во время обработки не вызывало ошибку изменения коллекции.
- **Сохранение без лишнего копирования:** карты симуляции связаны с данными сохранения мира и помечаются изменёнными при обновлении.

Оптимизации уменьшают лишнюю работу и количество временных объектов, но не являются обещанием фиксированного FPS: фактическая производительность зависит от размера мира, количества существ, других модов и компьютера.

## Установка

1. Установите Minecraft Forge **1.12.2-14.23.5.2859**.
2. Скачайте файл `LivingWorld-1.0.0.jar` со страницы релизов.
3. Поместите JAR-файл в папку `mods`.
4. Запустите игру с профилем Forge для Minecraft 1.12.2.

## Сборка из исходников

Для сборки требуется Java 8. В корне проекта выполните:

```bash
./gradlew clean build
```

Готовый JAR-файл появится в папке `build/libs/`.

## Совместимость с сохранениями

Living World сохраняет данные симуляции в файлах мира. Перед установкой, обновлением или удалением мода рекомендуется сделать резервную копию важных миров. Не рекомендуется без резервной копии переключаться между версиями мода, которые используют разные форматы сохранённых данных.
