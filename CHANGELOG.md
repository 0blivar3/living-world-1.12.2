# История изменений Living World

Здесь перечислены основные возможности, изменения и технические улучшения мода.

## [1.0.0] — Первый публичный релиз

### Добавлено: основа A-Life

- Добавлен менеджер A-Life, который обрабатывает игровые миры на стороне сервера.
- Добавлено отслеживание сущностей по UUID.
- Данные симуляции разделены по измерениям.
- Добавлено сохранение состояния существ между игровыми сессиями.
- Реализовано обновление данных сущностей с заданным интервалом.

### Добавлено: потребности и питание животных

- Добавлен показатель сытости.
- Реализовано постепенное уменьшение сытости со временем.
- Добавлен поиск пищи для подходящих животных.
- Травоядные могут искать и поедать траву.
- Для куриц и свиней добавлено естественное кормовое поведение.
- Куры и свиньи могут подбирать подходящие выпавшие предметы.
- Добавлены профили питания: травоядные, всеядные и хищники.
- Добавлено влияние длительного голодания на здоровье.
- Голод и его последствия учитываются также для существ в незагруженных чанках.

### Добавлено: охота

- Волки могут охотиться на овец и кроликов.
- Оцелоты могут охотиться на куриц и кроликов.
- Хищники ищут добычу в ограниченном радиусе, преследуют её и атакуют.
- Добавлено восстановление сытости после успешной охоты.

### Добавлено: стада и реакция на угрозы

- Добавлено формирование небольших стад.
- Реализовано объединение подходящих животных одного вида.
- Добавлены лидер и участники стада.
- Добавлена реакция животных на обнаруженных поблизости враждебных существ.
- Добавлен сигнал тревоги для стада.
- Поиск угроз для животных и жителей использует общий пространственный индекс.

### Добавлено: размножение

- Взрослые животные могут самостоятельно искать партнёров.
- При размножении проверяются возраст, здоровье, сытость и время восстановления.
- Добавлена стоимость размножения в виде расхода сытости.
- Добавлены задержки между циклами размножения.
- Добавлена дополнительная задержка перед новым размножением после взросления.
- Мулы исключены из размножения.
- Добавлена офлайн-симуляция размножения для поддерживаемых зарегистрированных типов животных.

### Добавлено: распорядок животных

- Добавлен простой ночной отдых для травоядных и всеядных животных.
- Время некоторых проверок распределяется индивидуально, чтобы уменьшить одновременную нагрузку.

### Добавлено: поведение жителей

- Добавлено определение дома и подходящей рабочей станции.
- Добавлено базовое перемещение жителей к дому и рабочему месту.
- Добавлено обнаружение ближайших враждебных существ.
- Жители могут пытаться покинуть опасную область.
- Поиск рабочих станций ограничен загруженными чанками.

### Добавлено: офлайн-симуляция

- Добавлена облегчённая симуляция существ в незагруженных областях.
- В офлайн-режиме учитываются возраст, сытость и последствия голодания.
- Добавлено создание виртуальных записей потомства без немедленного создания Minecraft Entity.
- Виртуальное потомство материализуется при естественной загрузке соответствующего чанка.
- Добавлена проверка UUID для предотвращения дублирования сущностей.
- Реализована работа с данными по измерениям.
- Офлайн-симуляция не загружает чанки принудительно.

### Оптимизация производительности

- Добавлен пространственный поиск кандидатов для офлайн-размножения вместо полного перебора всех животных.
- Поиск животных для вступления в стада оптимизирован с помощью пространственных ячеек и группировки по виду.
- Добавлен общий пространственный индекс враждебных существ для проверки угроз стадам и жителям.
- Индекс угроз строится один раз на цикл обновления и используется несколькими системами поведения.
- В трекере повторно используются временные списки, множества и карты.
- Уменьшено количество создаваемых объектов BlockPos при поиске травы и природной пищи.
- Оптимизирован поиск рабочих станций жителей: временные позиции переиспользуются.
- Некоторые поисковые проверки распределены по времени.
- Сокращены лишние проходы по спискам загруженных сущностей.
- Добавлен снимок списка сущностей для безопасной обработки появления и удаления существ во время обновления поведения.
- Данные симуляции связаны с хранилищем сохранения мира без постоянного копирования больших карт.
- Добавлена проверка загруженности чанка перед перемещением жителей к цели.
- Материализация виртуального потомства проверяет наличие уже загруженной сущности с тем же UUID.

### Исправления и технические изменения

- Исправлена ошибка ConcurrentModificationException при изменении списка сущностей во время обновления поведения.
- Предотвращено построение маршрута жителями в незагруженные чанки.
- Синхронизирована обработка времени восстановления размножения между загруженной и офлайн-симуляцией.
- Исключены мулы из размножения как в обычном игровом поведении, так и в офлайн-симуляции.
- Добавлена обработка метаданных мода при сборке, чтобы версия мода и версия Minecraft корректно подставлялись в mcmod.info.
- Удалён оставшийся отладочный вывод из основного класса мода.

### Техническая информация

- Целевая версия Minecraft: **1.12.2**.
- Целевая версия Forge: **14.23.5.2859**.
- Совместимость с **Java 8**.
